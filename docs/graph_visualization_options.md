# Варианты визуализации графа зависимостей

Документ для обсуждения выбора инструмента визуализации архитектурного графа микросервисов (Train Ticket: 40+ сервисов, БД, очереди).

## Требования к визуализации
- **Направленность и слои:** строгая иерархия вызовов (Gateway -> Services -> DB / MQ), а не хаотичный физический клубок.
- **Группировка (Compound nodes):** объединение таблиц БД и эндпоинтов внутри соответствующих сервисов/баз.
- **Инспекция ребер (Evidence):** клик или ховер по ребру показывает источник (`AST_EXACT`, `CONFIG`, `ML_PREDICTED`), файл, номер строки и `confidence`.
- **Подсветка Blast Radius:** при выборе узла визуально выделяются все зависящие от него сервисы (upstream/downstream).
- **Local-First:** рендер без обращения к внешним CDN и облачным сервисам.

## Кандидаты

### 1. Cytoscape.js (с dagre или elk)
Классический движок анализа графов на Canvas.
- **Плюсы:**
  - Нативная поддержка вложенных узлов (compound nodes).
  - Иерархические алгоритмы раскладки (Dagre, ELK).
  - Встроенный обход графа (поиск путей, соседей для подсветки Blast Radius).
  - Упаковывается в единый автономный HTML-файл без сборщиков и dev-сервера.
- **Минусы:**
  - Императивный API, стилизация через JSON-селекторы.

### 2. React Flow (xyflow)
Компонентный канвас на базе React DOM/SVG.
- **Плюсы:**
  - Высокая визуальная привлекательность для демонстрации жюри.
  - Узлы — полноценные React-компоненты (карточки сервисов со стеком, списком портов, метриками).
  - Простая интеграция интерактивных фильтров (слайдер порога confidence, чекбоксы источников).
- **Минусы:**
  - Требует инфраструктуру фронтенда (React, Vite, билд).
  - Лейаут рассчитывается внешней библиотекой (например, `elkjs`).
  - При масштабе более 500-1000 DOM-элементов производительность ниже, чем у Canvas.

### 3. PyVis (vis-network)
Быстрый экспорт из Python/NetworkX в HTML.
- **Плюсы:**
  - Генерация в 3-5 строк кода прямо из Python-скрипта.
- **Минусы:**
  - Force-directed физика превращает 40 сервисов в трудночитаемый клубок.
  - Нет нативных иерархических контейнеров (compound nodes).
  - Сложно кастомизировать панель с Evidence Log.

### 4. Graphviz (pygraphviz / dot)
Статический генератор иерархических диаграмм.
- **Плюсы:**
  - Идеальная раскладка DAG без ручной настройки.
- **Минусы:**
  - Статический SVG/PNG, нет интерактивности (зум, клик по ребру, фильтрация).

## Сравнение

| Критерий | Cytoscape.js + ELK | React Flow | PyVis | Graphviz |
| :--- | :--- | :--- | :--- | :--- |
| Иерархический поток (DAG) | Отлично | Отлично (через elkjs) | Слабо | Отлично |
| Вложенные группы (сервис -> БД) | Да | Да | Нет | Да |
| Детали ребра по клику (Evidence) | Да (тултип / сайдбар) | Да (нативный UI) | Базовый тултип | Нет |
| Подсветка Blast Radius на клиенте | Да (встроенный API) | Да (через state) | Сложно | Нет |
| Автономный единый HTML-файл | Да | Нет (нужен билд) | Да | Да (SVG) |
| Трудозатраты | 2-3 часа | 1-2 дня | 30 минут | 30 минут |

## Предложение к обсуждению

1. **Базовый вариант (этап отладки):**
   Генерировать один локальный HTML-файл на **Cytoscape.js** с раскладкой **Dagre** скриптом из Python-пайплайна. Закрывает задачи отладки, поиска изолированных узлов и проверки Evidence Log без поднятия веб-сервера.
2. **Расширенный вариант (этап защиты):**
   Если останется время перед сдачей — собрать интерактивный дашборд на **React Flow** с интеграцией локального MCP-сервера для живой демонстрации ИИ-агента.
