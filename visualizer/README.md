# Archonity Visualizer

> **Устарело.** Описывает визуализатор графа сервисов по ADR-001. `run_eval.py` по-прежнему пишет данные в `public/data/`, но под трассу сценария визуализатор не переделан ([ADR-002](../docs/adr/adr-002_react_flow_visualizer.md), [roadmap.md](../docs/roadmap.md)).

Интерактивный Single Page Application (SPA) визуализатор архитектурного графа микросервисов для проекта **Archonity** (бенчмарк Train Ticket, 40+ сервисов).

Разработан в соответствии с [ADR-002](../docs/adr/adr-002_react_flow_visualizer.md) и `Дорожной картой` (удалён, в истории git).

---

## Возможности

- **Интерактивный холст на React Flow (`@xyflow/react` v12):** масштабирование, панорамирование, миникарта с цветовой дифференциацией.
- **Иерархическая DAG-раскладка на `elkjs`:** автоматическое упорядочивание потоков вызовов (Gateway $\to$ Services $\to$ DB/MQ) без пересечений. Поддержка ориентации слева направо (LR) и сверху вниз (TB).
- **Кастомные карточки компонентов:**
  - `ServiceNode` (Spring Boot, порты, базовые пути, бейджи эндпоинтов).
  - `DatabaseNode` (MySQL/MongoDB с перечислением таблиц).
  - `QueueNode` (RabbitMQ с маршрутами).
- **Плавающий тулбар:**
  - Слайдер порога уверенности ML ($p \ge \text{threshold}$) с мгновенным отсечением слабых гипотез.
  - Чекбоксы источников: детерминированный `AST`, конфигурации `Config`, предсказания `ML`, арбитраж `LLM Judge`, транзитивные связи `Transitive`.
  - Переключатель цветовой палитры: «По источникам данных» vs «По протоколам связи».
  - Поисковая строка с автоподсветкой сервисов, эндпоинтов и таблиц.
- **Инспектор доказательств (Evidence Log):**
  - При клике на любое ребро: полный аудит (файл, строка кода, сниппет, цепочка вызовов `Call Chain`, признаки `CatBoost` или структурированный вердикт `LLM-as-a-Judge`).
- **Калькулятор Blast Radius:**
  - При клике на узел: вычисление прямого и транзитивного радиуса поражения при изменении сервиса с интерактивной подсветкой графа и затемнением неаффектированных узлов.

## Запуск в разработке

```bash
cd visualizer
npm install
npm run dev
```

Приложение доступно по адресу `http://localhost:5173/`.

## Сборка в продакшен

```bash
cd visualizer
npm run build
```

Статический билд сохраняется в директорию `dist/` и не требует бэкенд-сервера.
